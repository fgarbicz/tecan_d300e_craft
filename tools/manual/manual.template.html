1. What Craft is — and what it is not

Craft writes the same protocol files (.tdd) as Tecan's D300e Control 4.0.1. You design the experiment on any computer, copy the file to the D300e computer, open it in D300e Control and run it there. Craft never talks to the instrument.

Next to each .tdd Craft saves an experiment file (name.craft.json) with what the D300e does not need: cell lines, well roles (blank, excluded), the units you prefer for each drug, and the plate-reader values. Keep both files together.

Always open the protocol in D300e Control and check it before dispensing. D300e Control works out the volumes itself from the doses in the file, so what lands in the wells is decided there. Craft's run plan (cassettes and loads) is a prediction that matched D300e Control on every run it was compared with; compare it once with D300e Control's own loading table on your first run of a new kind of experiment.

Craft is a clean-room program: it was built from protocol files and run reports saved by D300e Control and from the D300e user guide. It contains no Tecan code.

2. Installing

Mac
…_aarch64.dmg (Apple silicon). Open the .dmg and drag the app to Applications. The app is not notarized: the first time, right-click it → Open → Open (or System Settings → Privacy & Security → Open Anyway).
Windows 10/11
…_x64-setup.exe (installs for the current user, no admin rights needed) or …_x64_en-US.msi (for IT deployment). The installer is not signed: in the SmartScreen window choose More info → Run anyway. Uses Microsoft Edge WebView2, which Windows 10/11 already has; the setup installs it if missing.
Linux
…_amd64.deb (Ubuntu/Debian: sudo apt install ./file.deb), ….rpm (Fedora), or …_amd64.AppImage (any distribution: chmod +x, then run it). Needs WebKitGTK 4.1, which current desktop distributions include.

The installers are on the repository's Releases page. The same interface also runs in a web browser for development (bin/serve.sh, then http://127.0.0.1:8931/app/); in the browser, Save downloads the files instead of writing them in place.

3. Words used in this manual

Stock
The tube of drug you pipette into a dispense head, e.g. Bortezomib 10 mM in DMSO.
Dose
The final concentration in the well after printing, e.g. 10 nM. Each drug can be shown in its own unit (mM, µM, nM, pM, or mass units); the file for the D300e always stores the same value.
Dilution step
How much lower each next dose is: 1:3 means each dose is a third of the one before. Give a step, or a highest and a lowest dose and let Craft work out the step.
PBS border
The outer row and column of the plate, filled by hand with PBS or medium so the inner wells do not dry out. The D300e does not print there, except priming wells.
Priming ("scrap") well
A border well that gets at least 30 nL of each drug first, so the head is running properly before the tiny doses (Tecan's recommendation).
Diluted stock (fluid shift / extend)
When a dose would need less than one drop of the stock, Craft adds a second tube of the same drug, diluted, e.g. Bortezomib - 1:30. Shift: the whole series comes from the diluted tube. Extend: the low doses come from the diluted tube (those that need up to about 180 nL of it), the high doses from the stock. D300e Control does the same and picks the same dilution factors (2–9, 10–90, 100–900, 1000–9000).
DMSO top-up (normalization)
Plain DMSO added so that every well, the controls included, contains the same amount of solvent. "Same DMSO in every well" tops every well up to the well with the most.
Cassette and dispense head
T8+: 8 small heads. D4+: 4 high-volume heads, used when a head needs more than a T8+ holds. Each head holds one solution; the run plan says what to pipette into which head and how much (the load, which includes what the head needs beyond the dispensed volume).
Randomization
The D300e prints each dose into another well of the same cell line, in a random order saved in the protocol. Craft shows the plate as planned (tidy layout, where you edit) or as printed (where each dose really lands). Results are always matched to where the dose was printed.
Blank / vehicle
Vehicle: cells with DMSO only (100 % viability). Blank: medium without cells (background), marked in Annotate.

5. At the D300e

  1. Copy the .tdd (and the .craft.json, so the results open later) to the D300e computer, e.g. through OneDrive or a USB stick.
  2. In D300e Control: File → Open the .tdd. Look at plate 1: drugs, doses and — on a randomized plate — the scattered layout should match Craft's As printed view.
  3. Press Run. D300e Control shows which cassettes to insert and what to load into each head. Compare it with Craft's Run tab (the drawing you printed). If they differ, follow D300e Control and tell the person who looks after Craft.
  4. Seed the cells and fill the border with PBS as the Cell lines view shows, then load the plates when the D300e asks.
  5. Keep D300e Control's run report (Reports folder): it records what was actually dispensed.

6. Editing plates by hand

Everything the wizard makes can be changed by hand, and Craft opens any protocol saved by D300e Control. Select wells by dragging, Shift-click to extend, Ctrl-click (⌘-click on a Mac) to add wells, or click a row or column header. Then use a tab on the right:

TabWhat it does
SetGive the selected wells one concentration of one drug (or remove it).
TitrateA series of doses across the selected wells, e.g. 8 doses × 3 wells each = select 24 wells. Highest dose and step, or highest and lowest.
SynergyD300e Control's synergy builder: a full matrix of two or three drugs on one plate (no replicates; for replicates and cell lines use the wizard).
NormalizeDMSO top-up of the selected wells so they all contain the same amount. Include the no-drug wells: they become the vehicle controls.
AnnotateCell lines, blanks and excluded wells; randomize or de-randomize a plate or all plates.
CheckEverything the D300e would refuse or warn about, with the wells to look at; DMSO per well; priming.
RunCassettes, dispense heads and loads, as a drawing (save it as SVG or PNG) and as tables.
ResultsPaste plate-reader values, see viability and synergy, export Excel or a SynergyFinder package.

Copy and Paste carry wells with their drugs, normalization, cell lines and roles. Undo (Ctrl+Z / ⌘Z) undoes any change, including a whole wizard run. The colour theme is chosen with the dots in the top-right corner.

7. Results, synergy and Excel

  • Paste each plate's values in the Results tab, copied from the plate reader's Excel export (row and column labels are fine). One paste per plate; switch plates in the list on the left.
  • % of vehicle uses the wells with DMSO only on the same plate and cell line; mark medium-only wells as blank in Annotate to subtract background.
  • Bliss excess (shown in the app) is how much more the pair kills than expected if the two drugs acted independently. For ZIP, HSA and Loewe, Save package writes the data in SynergyFinder's format with an R script; Save + render also runs it (desktop app, needs the synergyfinder conda environment).
  • Export Excel: one row per well (plate, well, cell line, role, every drug's concentration in its unit, DMSO %, raw signal, % of vehicle), replicate statistics per condition and the Bliss table.
The analysis is checked by Craft's own tests, not against another analysis program. Check your first analysis against a hand calculation before relying on it.

8. Command line and Claude

The repository contains a command-line version of the designer (needs Node.js 20 or newer). It turns a short JSON description into the protocol, the experiment file and a bench plan in Markdown:

bin/d300craft example > spec.json        # an example to edit
bin/d300craft design spec.json --out experiments/my-run
bin/d300craft plan my-run.tdd             # plan for any protocol
bin/d300craft check my-run.tdd            # warnings only
bin/d300craft dosemap my-run.tdd          # dose map (SVG)

A spec can give doses as "top": "10 µM", "bottom": "0.1 nM", "levels": 10 or with a "dilution": "1:3", a unit per drug ("unit": "nM"), diluted stocks (on by default) and "randomize": "cellLine". Claude uses the same tool through the d300-plate-design skill, so you can ask it to "design synergy plates for these drugs on these cells".

10. Troubleshooting

ProblemWhat to do
The wizard says "Not ready yet"The message says what does not fit and what would fit (fewer doses, fewer wells per dose, more plates). Change one of them.
A dose is "below one drop"Keep "Add a diluted stock" ticked in step 1, or lower the stock concentration.
Too much DMSO in some wellsLower the highest dose, use a more concentrated stock, or raise the DMSO limit if your cells tolerate it.
Randomized protocol saved with a version before 0.3.0 prints a different patternOlder versions saved the shuffle in the reverse direction. Open the file, press Shuffle again and save.
The dose map export shows the tidy layout of a randomized plateExpected: it shows the plan. For the printed positions use the As printed view.
Mac: "cannot be opened because the developer cannot be verified"Right-click → Open → Open, once.
Windows: "Windows protected your PC"More info → Run anyway.
Linux: the AppImage does not startchmod +x the file; on Ubuntu 24.04 and newer also sudo apt install libfuse2t64, or use the .deb.
